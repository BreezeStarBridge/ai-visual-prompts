## 📌 精选提示词

- **分类**: 3D 与美学设计
- **提示词 (Prompt)**:
  ```text
  Minimalist 3D isometric geometry, Morandi color palette, clean smooth surfaces, soft ambient studio lighting, dusty blue and warm grey tones, subtle depth of field, 8k resolution --ar 16:9
  ```
